# MaintainPro conservative cleanup — October 10, 2026

- `includes/components/activity.php`: orphaned dashboard component with no include, route, test, or dynamic reference. Its reusable `.activity-item` styles remain because current action-plan progress views use them.
- `tests/tmp/`: 823 reproducible browser/PDF QA artifacts totaling 32,870,191 bytes. The isolated test runners recreate this directory and its contents when needed.

Total generated data removed: 32,870,587 bytes.

- Every `.htaccess` file and `config/mail.local.php`
- `.data` SQL backup, application logs, and release archives
- Protected evidence and profile uploads
- Database migrations and migration history
- `concern.php`, `concerns.php`, and `new-complaint.php` compatibility routes
- Historical implementation/audit documentation
- Bundled Bootstrap, SweetAlert, PHPMailer, and Dompdf dependencies
- Tests and test infrastructure

The project has no Node package cache, Composer cache, build output directory, checked-in runtime database, or obsolete root stylesheet to remove. Further deletion based only on filename/reference searches would risk compatibility URLs, deployment tooling, historical recovery information, or security tests.
